# Overview
- **ProcessRecipe** owns work semantics
- **ARConfig** owns concrete reusable AR content
- **PresentationStrategy** owns permissible mapping from needs -> presentation
- **FeedbackCapability** describes what a reusable Feedback can communicate
- **AssistanceRequirement** describes what this operator needs now
- **AssistancePlan** is the transient personalized result
